# Galactic-orbit probe

> **Status:** Spec: trade study v0.1 (Markdown + PDF) in docs/. No flight software or hardware.

A probe that leaves the solar system at up to ~100 km/s and then coasts on its own orbit around the Milky Way, like a free-floating star.

## Where this came from

This idea came up in a chat with one of Joshua Almeida's bots (Space bot, Oct 20 2026) and was not taken further at the time. This repo records it so it can be picked up later.
